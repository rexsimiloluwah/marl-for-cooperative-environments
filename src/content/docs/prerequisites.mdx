You do **not** need previous experience with multi-agent reinforcement
learning.

A basic foundation in the following areas is enough.

## Mathematics

You should be comfortable with:

- basic algebra;
- sums and averages;
- basic probability;
- reading simple mathematical notation.

**Review resources:**

- [Khan Academy: Algebra](https://www.khanacademy.org/math/algebra)
- [Khan Academy: Probability and Statistics](https://www.khanacademy.org/math/statistics-probability)

Advanced calculus and mathematical derivations are not required.

## Python

You should be able to read:

- variables and functions;
- lists and dictionaries;
- loops and conditionals;
- simple NumPy operations.

**Review resources:**

- [Python Tutorial](https://docs.python.org/3/tutorial/)
- [NumPy Quickstart](https://numpy.org/doc/stable/user/quickstart.html)

The labs provide most of the implementation. You will mainly complete small
pieces of code, run experiments, and interpret results.

## Reinforcement Learning

You should understand:

- agents and environments;
- observations and actions;
- rewards and returns;
- policies.

**Review resource:**

- [Reinforcement Learning](/background/reinforcement-learning/)

The Background section develops the RL and MARL foundations needed before
**Chapter 1: Coordinate**.

## Google Colab

The Communicate, Adapt, and Challenge labs use Google Colab.

You should know how to:

- run a notebook cell;
- change a value and rerun a cell;
- inspect plots and outputs.

**Review resource:**

- [Google Colab](https://colab.research.google.com/)

The notebooks use the
[`cooperative-marl-labs`](/resources/python-package/) package and are designed
to run on free Colab CPU sessions.
