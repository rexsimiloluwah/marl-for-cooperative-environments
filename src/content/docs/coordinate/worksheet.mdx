## 2 · Calculate the Joint-Action Space

<Question id="co-ws-ja1" n="2.1" numeric={625} notes={false} unit="joint actions">
Four agents each have five possible actions. How many joint actions are
possible?

<Fragment slot="hint">
Every choice by agent 1 combines with every choice by agent 2, and so on. The
count is a product, not a sum.
</Fragment>
</Question>

<Question id="co-ws-ja2" n="2.2" numeric={15625} notes={false} unit="joint actions">
Now six agents, still five actions each.

<Fragment slot="hint">
$5^6$. Two more agents multiplied the previous answer by 25.
</Fragment>
</Question>

## 3 · Calculate a VDN Team Value

Under VDN the team value is the sum of the individual values,
$Q_{\text{tot}} = \sum_i Q_i$.

<Question id="co-ws-vdn1" n="3.1" numeric={9.9} tolerance={0.05} notes={false}>
Given $Q_1 = 3.2$, $Q_2 = 2.6$ and $Q_3 = 4.1$, calculate $Q_{\text{tot}}$.
</Question>

<Question id="co-ws-vdn2" n="3.2" numeric={10.7} tolerance={0.05} notes={false}>
Agent 2 switches to an action with $Q_2 = 3.4$. What is the new team value?

<Fragment slot="hint">
Only one term changed. You do not need to add all three again.
</Fragment>
</Question>

## 5 · Evaluate the CTDE Trade-off

> Ten warehouse robots must act independently at deployment. During training,
> the simulator provides the complete warehouse state.

<Question id="co-ws-decide" n="5.1" rows={4} placeholder="Two or three sentences.">
Would you prefer fully independent learning or CTDE here? What is the main
trade-off in your choice?
</Question>

<AnswerKey>

<Answer n="1">
Independent learning · CTDE · centralized critic · VDN · QMIX.

If one tripped you up it is probably **CTDE** against **centralized critic**:
CTDE is the paradigm that permits global information during training, and a
centralized critic is one way of using it.
</Answer>

<Answer n="2.1">
$5^4 = 625$.
</Answer>

<Answer n="2.2">
$5^6 = 15{,}625$. Two extra agents multiply by $5^2 = 25$, not by 2.
</Answer>

<Answer n="3.1">
$3.2 + 2.6 + 4.1 = 9.9$.
</Answer>

<Answer n="3.2">
$9.9 - 2.6 + 3.4 = 10.7$. Under a plain sum, one agent changing action moves
the team value by exactly its own change.
</Answer>

<Answer n="4.1">
$5^{10} = 9{,}765{,}625$. The tenth agent added more joint actions than the
first nine combined.
</Answer>

<Answer n="5.1">
No single right answer. A good one names what it gives up.

**CTDE** is the strong default: the simulator's state costs nothing during
training, execution is local either way, so refusing it buys nothing. Price:
one more component to train and debug.

**Independent learning** is defensible under time pressure. It needs no new
algorithm, keeps per-agent cost flat as the fleet grows, and is the baseline
CTDE has to beat. Price: non-stationarity and high variance across seeds.
</Answer>

</AnswerKey>
